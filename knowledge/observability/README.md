# Observabilidade de Missões

Este diretório guarda apenas o resumo mensal, versionado e não sensível, das missões relevantes do PM Loadout.

- Arquivo: `YYYY-MM.md`.
- Formato de cada entrada: o YAML definido em [services/observability.md](../../services/observability.md).
- Dono da consolidação: `agente-evolucao`, no primeiro ciclo útil do mês seguinte.
- Crie o arquivo mensal somente quando houver uma entrada autorizada.

Não registre PII, credenciais, transcrições, conteúdo de pesquisa bruta ou métricas de desempenho individual.
