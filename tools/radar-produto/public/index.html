Vertical Tech — Delivery, direto do ClickUp (aplicação local)

—
Solicitante, empresa e outros metadados aparecem ao abrir o detalhe de uma tarefa — buscar isso para todas as tarefas de uma vez seria custoso na API do ClickUp, então é buscado sob demanda. Desde a mudança estrutural de 2026-09-10, Discovery deixou de ser uma lista/esteira própria no ClickUp — descoberta agora é uma faixa de status dentro do Backlog de cada squad (ver knowledge/domains/processo.md). Este painel ainda não foi revisado para refletir essa faixa. Editar status, prioridade, prazo e responsáveis só fica disponível para tarefas dos seus times (Plataforma e Backoffice & Integração) — grava direto no ClickUp assim que você muda o campo. Esta é uma aplicação local: os dados vêm da API do ClickUp através do seu próprio servidor em localhost; o token nunca chega ao navegador.
