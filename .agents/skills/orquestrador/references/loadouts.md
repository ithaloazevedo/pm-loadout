# Loadouts

Loadouts são bundles reutilizáveis. O Orquestrador pode equipá-los como estão ou aparar as skills desnecessárias.

## Starter Loadout

Use para trabalho de produto vago.

- `brainstorming`
- `vieses`
- `advogado-do-diabo`

## Discovery Loadout

Use para entendimento de usuário e discovery de oportunidades.

- `entrevista`
- `entrevista-usuario`
- `jtbd`
- `mapa-necessidades`
- `suposicoes`
- `ost`

## Evidence Loadout

Use para decisões que dependem de fatos externos, linguagem de domínio ou evidência auditável.

- `pesquisa-verificavel`
- `modelagem-dominio`
- `vieses`

## Strategy Loadout

Use para priorização, estratégia e sequenciamento.

- `gist`
- `ice`
- `wardley`
- `cynefin`
- `advogado-do-diabo`

## Spec Loadout

Use para transformar decisões de produto em artefatos no ClickUp.

- `clickup-spec`
- `checar-servico`
- `checar-usabilidade`

## Launch Loadout

Use para decisões de go-to-market e prontidão de lançamento.

- `nivel-lancamento`
- `metricas`
- `checar-servico`
- `retrospectiva`

## Regra

Equipe um loadout nomeado só quando a maioria das skills é relevante. Caso contrário, selecione skills individuais.

`handoff` e `setup-pm-loadout` não entram em loadouts: são ações explícitas de continuidade e configuração.
